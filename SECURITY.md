# Security policy

## Reporting a vulnerability

Email **contact@cmssy.com** with "Security" in the subject. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the affected version of `@cmssy/mcp-server`. We reply within 3 business days and keep you updated until it is fixed.

## Supported versions

Only the latest published version of `@cmssy/mcp-server` receives fixes.
